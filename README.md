# Ángulo de Maniobra

App web (index.html) que sigue el giro del coche al aparcar y pita a 25° y 45°. Se enciende con un silbido (un trozo de cualquier melodía) o con el botón «Poner a 0°», y se apaga con otro silbido o sola al minuto.

GitHub Actions compila el APK de Android en cada cambio en `main` (carpeta `android/`) y lo publica en Releases:
https://github.com/antoinechevreaux-sudo/Angular/releases/latest/download/Angulo.apk
